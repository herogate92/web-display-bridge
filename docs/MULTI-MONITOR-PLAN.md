# 다중 모바일 확장 모니터 지원 계획

## 요약

WebDisplay Bridge에서 가상 모니터를 1~4대까지 추가하고, 아이패드·아이폰·안드로이드 기기를 각각 독립된 Windows 확장 화면으로 연결한다. VDD Control을 별도로 열지 않고 앱에서 모니터 수를 변경하며, 각 화면은 별도의 QR 코드와 4자리 인증번호를 사용한다.

## 주요 변경

- 상단에 가상 모니터 수 1~4대 설정과 적용 버튼을 추가한다.
- 적용 시 관리자 확인을 받은 뒤 VDD 설정의 모니터 수를 변경하고 드라이버만 재시작한다.
- 변경 전 설정 파일을 백업하고, 재시작이나 장치 확인 실패 시 기존 설정을 자동 복구한다.
- 모니터 수 변경 전 실행 중인 전송을 종료하고 기존 화면 배치를 복구한다.
- 새 가상 모니터는 최초 한 번만 기존 화면 오른쪽 빈 공간에 배치한다. 이후 사용자가 Windows 디스플레이 설정에서 정한 위치를 유지한다.

## 다중 화면·연결 구조

- 가상 모니터마다 독립된 세션을 생성한다.
- 각 세션은 가상 모니터 장치 식별자, 개별 해상도·fps·최대 전송량, 4자리 인증번호와 QR 코드, 캡처 스트림과 WebRTC 연결, 연결 상태·실제 fps·전송량·코덱을 가진다.
- 하나의 로컬 웹 서버와 포트를 공유하되 인증번호별로 세션을 완전히 분리한다.
- 서로 다른 세션의 WebRTC 신호나 영상이 섞이지 않도록 sessionId를 모든 연결·신호·통계 데이터에 포함한다.
- 화면별 QR에는 해당 세션 주소를 넣는다. 메인 주소에서는 4자리 번호를 입력해 같은 세션으로 들어간다.
- 한 화면에는 모바일 기기 한 대만 연결한다. 기존 기기의 재접속은 허용하고 다른 기기의 중복 접속은 거부한다.
- 모바일 기기 한 대가 60초 이상 끊기면 해당 가상 화면과 세션만 종료한다. 다른 화면은 계속 유지한다.
- 전체 종료와 비정상 종료 복구는 최초 연결 전 Windows 화면 구성을 복원한다.

## PC 화면과 인터페이스

- 제목을 모바일 기기 연결로 통일하고 아이패드 전용 표현은 해상도 프리셋에만 사용한다.
- 각 가상 모니터를 한 행으로 표시한다. 왼쪽에는 해상도·fps·전송량·연결/종료, 오른쪽에는 작은 QR 코드·큰 4자리 인증번호·접속 주소를 배치한다.
- 화면별로 아이패드 9 프리셋과 직접 입력 해상도를 제공한다.
- 연결된 기기의 종류와 관계없이 Safari, Chrome 등 WebRTC 지원 브라우저를 사용한다.
- 4대 구성에서는 화면이 길어질 수 있으므로 모니터별 접기 기능과 상단 상태 요약을 제공한다.

## API와 데이터 변경

- 단일 StreamConfig와 전역 상태를 DisplaySession 배열 구조로 변경한다.
- IPC에 모니터 수 변경, 세션별 시작·종료, 전체 종료 기능을 추가한다.
- 화면 캡처 요청에 세션 식별자를 연결해 정확한 VDD 화면만 선택한다.
- CCD 보조 프로그램에 기존 복구 기록을 유지하면서 가상 화면 추가 활성화, 지정 화면 하나만 비활성화, 현재 수동 배치를 보존한 해상도 변경, 전체 원래 배치 복구 기능을 추가한다.
- 기존 단일 화면 설정과 복구 기록은 읽을 수 있도록 호환한다.

## 테스트 및 완료 기준

- VDD 수를 1→2→4→1로 변경했을 때 Windows가 정확한 개수의 독립 모니터를 인식한다.
- 아이패드와 안드로이드에서 서로 다른 QR로 접속해 서로 다른 Windows 창을 동시에 표시한다.
- 한 화면의 해상도를 변경하거나 연결을 종료해도 다른 화면과 영상은 유지된다.
- 세션 간 인증번호, WebSocket 신호, 영상, 통계가 섞이지 않는다.
- 만료·재사용 번호와 이미 사용 중인 화면의 두 번째 기기 접속을 거부한다.
- VDD 재시작 실패, Wi-Fi 단절, 앱 강제 종료 후 기존 화면 구성을 복구한다.
- 실제 장비에서 독립 화면 2개를 10분 이상 동시에 전송해 기능과 안정성을 확인한다.
- 1~4대 모두 기능적으로 연결되도록 검증하되, 60fps 성능 목표는 화면별 설정과 PC 인코더 한도에 따라 측정 결과를 표시한다.
- 자동검사에는 VDD 설정 백업·복원, 다중 세션 격리, 개별 종료, 인증 만료, CCD 다중 화면 복구를 포함한다.

## 확정된 기본값

- 가상 모니터 수: 1~4대 선택
- VDD 변경: 앱에서 관리자 확인 후 자동 처리
- 기기 배정: 화면별 QR 코드와 4자리 번호
- 품질: 화면별 개별 설정
- 화면 위치: Windows 디스플레이 설정에서 사용자가 조정
- 장시간 연결 해제: 해당 화면만 종료
- 최초 활성화 위치: 기존 화면 오른쪽
- 첫 완료 기준: 아이패드 1대와 안드로이드 1대를 독립 확장 모니터 2대로 동시 사용
