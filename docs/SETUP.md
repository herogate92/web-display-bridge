# 설치와 연결

## 1. 가상 디스플레이 드라이버

공식 [Virtual Display Driver 25.7.23](https://github.com/VirtualDrivers/Virtual-Display-Driver/releases/tag/25.7.23)의 Control 앱으로 드라이버를 최초 한 번 설치합니다. 드라이버 버전과 다운로드 해시는 프로젝트의 driver.lock.json에 고정되어 있습니다.

드라이버를 설치한 뒤에는 WebDisplay Bridge 상단에서 가상 모니터 수를 1~4대로 변경할 수 있습니다. 관리자 확인 창을 승인하면 앱이 VDD 설정을 백업하고 드라이버를 다시 시작합니다. 가상 모니터 수를 바꾸면 실행 중인 모든 전송이 종료됩니다.

가상 모니터를 Windows 기본 모니터로 지정하지 마세요. 새 가상 화면은 처음 켤 때 기존 화면 오른쪽에 놓이며, 이후 Windows 디스플레이 설정에서 원하는 위치로 옮길 수 있습니다.

## 2. Windows 앱 실행

앱 상단에서 모바일 기기와 같은 네트워크의 PC 주소를 고릅니다. 각 가상 화면 카드에서 해상도, 프레임률과 최대 전송량을 선택한 뒤 해당 화면의 연결 시작 버튼을 누릅니다.

아이패드 9용 기본 해상도는 1440×1080 60fps입니다. 느리면 1080×810 또는 30fps를 사용하세요. 목록에 없는 짝수 해상도는 직접 입력할 수 있으며, 처음 추가할 때 관리자 확인과 VDD 재시작이 필요합니다.

방화벽 알림이 나오면 개인 네트워크에서 WebDisplay Bridge를 허용합니다. WebDisplay Bridge는 로컬 HTTP 8443 포트와 WebRTC 연결을 사용하며 외부 계정이나 중계 서버를 사용하지 않습니다.

## 3. 모바일 기기 연결

- 아이패드와 아이폰은 Safari, 안드로이드 기기는 최신 Chrome을 사용합니다.
- 연결할 가상 화면 카드의 QR을 스캔하거나 PC주소:8443에 접속해 그 카드의 4자리 번호를 입력합니다.
- QR과 번호는 5분 동안 유효하고 해당 가상 화면에 기기 한 대만 연결합니다.
- 화면마다 QR과 번호가 다르므로 여러 모바일 기기에서 서로 다른 Windows 확장 화면을 동시에 사용할 수 있습니다.
- 연결이 끊기면 60초 동안 재접속을 기다린 뒤 해당 가상 화면만 종료합니다. 다른 화면은 계속 전송됩니다.

PC 키보드와 마우스로 Windows 화면 사이를 이동합니다. 소리는 PC에서 재생됩니다. 모바일 기기 화면 비율과 선택한 해상도 비율이 다르면 전체 화면에서 여백이 생길 수 있습니다.

## 복구와 제거

- 해당 화면 종료는 선택한 세션만 종료합니다. 마지막 세션을 종료하면 앱 실행 전 Windows 화면 배치를 복구합니다.
- 전체 연결 종료는 모든 영상 전송을 끊고 최초 화면 배치를 복구합니다.
- 앱이 비정상 종료되면 다음 실행 시 display-recovery.json을 사용해 복구합니다. 복구 전에는 이 파일을 삭제하지 마세요.
- 가상 화면에 창이 남으면 Win+Shift+왼쪽/오른쪽 화살표로 실제 모니터로 이동합니다.
- 제거 순서는 WebDisplay Bridge 전체 연결 종료, VDD Control에서 드라이버 제거, Windows 앱 설정에서 WebDisplay Bridge 제거입니다.

## 오류 구분

| 증상 | 확인할 항목 |
|---|---|
| 가상 모니터가 없음 | VDD 설치 여부와 앱 상단 모니터 수 |
| 모니터 수 변경 실패 | 관리자 확인 승인, VDD 설치 경로, 드라이버 재시작 |
| 페이지가 열리지 않음 | PC 주소, 같은 Wi-Fi, 개인 네트워크 방화벽 |
| 번호가 거부됨 | 해당 화면이 이미 사용 중인지, 5분이 지났는지 |
| 영상 연결 실패 | 게스트 Wi-Fi 기기 격리, VPN 또는 UDP 차단 |
| 화면이 느림 | 해상도와 전송량을 낮추거나 30fps 선택 |
